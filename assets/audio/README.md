# Audio de NeuroBreak

- `ambient/`: paisajes sonoros suaves para acompañar futuras sesiones de Flow.
- `notifications/`: avisos no intrusivos para alertas de bienestar, pausas o recordatorios.
- `feedback/`: sonidos cortos de interacción, confirmaciones y logros.

Mantén los archivos optimizados para escritorio (por ejemplo, `.mp3`, `.ogg` o `.wav`) y usa nombres descriptivos. La reproducción aún no está implementada; esta estructura permite añadirla sin reorganizar los assets.
